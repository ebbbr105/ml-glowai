# Проверка распределений и персонализации Pantavou

Дата: 5 ноября 2026. Статус: **разведочный эксперимент** (не подтверждение гипотезы).

## Что реально распределено в данных

После удаления неоднозначно дублированных анкет: **383 опроса, пять человек, 60 человеко-дней**.

Частоты TSV от −3 до +3: **22, 18, 35, 95, 47, 92, 74**. Это *упорядоченная дискретная* переменная. Нормальное (гауссово) распределение классов здесь не является обязательным или обоснованным допущением.

Медианная температура: **+30,33 °C**. Только два человека наблюдались ниже +17 °C. При этом первый день, использованный как стартовая личная история, содержит всего **33 ответа** пяти человек при **+33,43…+35,40 °C** (средняя +34,26 °C); весь остальной тест — **350 ответов** при **+7,11…+36,47 °C** (медианная +26,97 °C). Стартовый контекст сильно смещён в жару и не репрезентативен для поздних холодных наблюдений.

См. `results/tsv_distribution_by_person.csv`, `results/tsv_distribution.png`, `results/temperature_distributions.png`.

## Более обоснованная выборка для личной калибровки

**Общая модель:** оставляем одного из пяти людей полностью вне обучения общей порядковой модели (`Leave-One-Person-Out`). Для его прогноза на день D используем только его собственные оценки со дней **строго раньше D**.

Вместо произвольного выбора последних k ответов проверили стратегии с одинаковым размером истории и одинаковыми тестовыми строками:

- `recent_k`: последние k ответов (контроль).
- `quantiles_k`: k наблюдений, равномерно выбранных по **эмпирическим квантилям температуры среди доступных прежних ответов**. Это репрезентативность по погоде, а не искусственно заданное гауссово распределение. Отбор не зависит от меток TSV.
- `days_k`: разнообразие предыдущих дней: по одной температурно-типичной анкете с разных дат, затем заполнение недостающих мест.
- `all_past`: все предыдущие ответы, контроль.

На каждом дне модель и её коэффициенты обучаются только по доступному прошлому. Общая модель и тестовые 350 ответов идентичны во всех сравнениях.

## Полученные результаты — среднее по людям

| Калибровка | Accuracy ↑ | MAE ↓ |
|---|---:|---:|
| Без персонализации | 51,58% | 0,6203 |
| Последние 10 ответов | 52,25% | 0,6234 |
| Квантили температуры, 10 ответов | 51,87% | **0,6147** |
| Дни, 10 ответов | 50,91% | 0,6245 |
| Последние 20 ответов | 52,50% | 0,6178 |
| Квантили температуры, 20 ответов | 51,51% | 0,6296 |
| Дни, 20 ответов | 50,36% | 0,6273 |
| Все доступные прежние ответы | 51,09% | 0,6270 |

Примечание: Accuracy = средняя доля точного совпадения модального класса TSV, MAE = среднее абсолютное отклонение предиктивной медианы, сначала по человеку, затем по пяти участникам.

По сравнению с общей моделью температура-квантильная выборка из 10 ответов улучшает MAE лишь на **0,0057 TSV**. У трёх человек ошибка уменьшилась, у двух выросла. При bootstrap-ресэмплинге по пяти людям ориентировочный 95% интервал изменения MAE (общая минус личная) — **от −0,010 до +0,021**. Интервал включает ноль; эффект нельзя считать подтверждённым. Выбор лучшей стратегии из нескольких на этих же тестовых данных делает оценку дополнительно оптимистичной (multiple comparisons).

## Вывод

Проблема не решается «нарисовать нормальное распределение» или искусственно сбалансировать все семь классов. В исходных данных нет достаточного числа людей и повторных оценок одного человека при разнообразных температурах, особенно холодных. Нельзя отобрать наблюдения из будущего ради покрытия температур и затем честно назвать эксперимент проверкой адаптации при реальном использовании.

**Практический план:** оставить текущую общую модель как исследовательскую основу; в будущем собирать реальные собственные TSV разных людей в разных погодных условиях и по нескольким дням; отдельно проверить личные поправки, учитывая прежнюю температуру, дни и объём истории. Для научной защиты утверждать только: *на Pantavou репрезентативность личной истории изучена, надёжный выигрыш персонализации не доказан*.
