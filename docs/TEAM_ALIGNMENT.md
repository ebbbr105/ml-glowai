# Согласование с презентациями команды

GlowAI — **один продукт**, но разные исследовательские области:

1. Разработчик Артур: сценарий перед выходом, погодные API, расчёт UTCI, прогноз/рекомендация, сбор оценки, логи и устойчивость API.
2. ML/LLM-разработчик: экспериментальное предсказание **TSV** на Pantavou, M0 и личная поправка по реальным прошлым TSV, сравнение с baseline/бустингом, анализ ограничений. На данный момент модель **не** внедрена как подтверждённый продакшен-компонент. В рамках дальнейшей разработки ML/LLM-инженер также отвечает за разработку LLM-компонента рекомендаций и интеграцию инференса с бэкендом совместно с Артуром.
3. Продакт Всеволод: проверка пользы сценария для пользователя, сложность опросов, набор респондентов, план Active Learning и продуктовых метрик. Выборочный запрос обратной связи и retention D30 — **планы**, не доказанные эффекты.

Строгие разграничения:

- UTCI — физический индекс состояния среды, а не равнозначная персональная ML-модель.
- TSV — ощущаемая температура (порядковые категории); TPV — предпочтение изменения условий. Не смешивать.
- Прогноз TSV в известных измеренных условиях ≠ подбор одежды ≠ доказанное повышение комфорта.
- Полевой пилот «20 человек за 2–3 недели» — **план**, а не проведённое исследование. Метрики API `p95 <= 3 сек`, `>=95% успеха` — цели.
- Уменьшение числа запросов на 40%, улучшение retention — **гипотезы**, не результаты.
- Исследование не содержит DORN и не использует преимущественно indoor-данные для обоснования outdoor-качества.
